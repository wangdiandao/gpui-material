# gpui-material

基于 Rust 和 GPUI 的原生桌面 Material 3 Expressive 组件库。gpui-base 提供行为、输入、焦点和基础设施，gpui-material 定义主题、绘制、组件状态呈现和桌面自适应组合。

项目处于 P0 需求与来源评审。首版目标包括浅色与深色主题、品牌色和动态色、键盘与原生辅助技术、中文输入、RTL、窗口缩放和高 DPI。Windows 是主要验收平台，macOS 与 Linux 从 P1 起参与能力验证。各平台的验证范围见[平台与质量要求](docs/verification.md)。

安装说明、可运行示例和 Gallery 随对应生产组件发布。
