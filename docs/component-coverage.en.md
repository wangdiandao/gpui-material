# Component coverage matrix

[简体中文](component-coverage.md) · English

This matrix covers the [Material 3 component directory](https://m3.material.io/components) and the desktop compositions required by the project. Official component links correspond to the [pinned site snapshots](material-snapshot.md). Kotlin files refer to `commonMain/androidx/compose/material3/` in the [pinned Compose package](design-sources.en.md#source-code-and-algorithm-references). Android and Adaptive rows use their respective packages.

The categories are **Specification**, **Adaptation**, **Experimental**, and **Compatibility**. Specification and adaptation entries are required for the first complete candidate. P8 records whether to adopt or defer experimental entries. Compatibility work follows in later phases. The types are `component`, `primitive`, and `pattern`. Production entries in the table are `planned`. [Platform acceptance](verification.en.md)

The owning phase completes applicable sizes, tokens, visuals, interactions, motion, semantics, and evidence. **Desktop** means Windows 11 x64 with keyboard and pointer, light and dark themes, RTL, high DPI, and applicable screen readers. **Text** adds Windows Chinese IME. **Touch** adds real touch or touchpad evidence. Record touch evidence status separately when hardware is unavailable. macOS and Linux exploratory results can use the same categories.

All buttons is a navigation index. Independently exposed components are listed under their specifications. DragHandle, Label, placement, and layout helpers are verified with their owning primitive or component. The caller provides app navigation, result data, and business validation.
