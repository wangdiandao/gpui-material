# P0 Requirements and source freeze

English | [中文](P00.zh.md)

Material 3 Expressive defines visuals, interaction presentation, and desktop composition. Pinned gpui-base and GPUI supply behavior, input, and rendering. Scope covers the specification and adaptation entries in the [component matrix](../component-coverage.md), [design system requirements](../design-sources.md#material-specification), and [platform quality criteria](../verification.md). Experiments are evaluated against actual devices and needs. Compatibility work follows in later phases.

<a id="工作单元"></a>

## Deliverables

| Task | Prerequisites | Change scope | Acceptance criteria |
| --- | --- | --- | --- |
| P0-01 Documentation, licensing, and phase entry points | None | README, LICENSE, notices, documentation index, phase rules and status, root ignore rules | Navigation and phase references resolve. Git ignores root `AGENTS.md`. TOML parses and the phase state is unique. |
| P0-02 Verify and pin design, sources, and dependencies | None | `docs/design/`, `docs/architecture/` | Upstream releases, tags, package metadata, digests, site snapshots, and algorithm references agree. |
| P0-03 Verify component coverage | P0-02 | `docs/components/coverage.md` | Every official directory topic has a disposition. Each planned deliverable has a type, category, phase, status, platform, and acceptance direction. |
| P0-04 Define three-platform acceptance and P1 probes | P0-02, P0-03 | `docs/verification.md`, `docs/phases/P01.md` | Verification requirements cover Windows, macOS, and Linux. Probes have dependencies, passing criteria, and blockers. |

P0 allows the listed documentation, licensing, ignore rules, and status files. Dependencies freeze as a documented contract. P1 pins exact Cargo versions in probes. P2 establishes the production workspace and lockfile. Components enter implementation in their [owning phase](../phases.md).

## Initial platform revision

On 2026-11-13, the project owner set initial support to Windows 11 x64/MSVC. P1 and later initial-release phases verify required capabilities on that platform. macOS and Linux probes inform future support evaluations.
