# P0 需求与来源冻结

[English](P00.md) | 中文

以 Material 3 Expressive 定义视觉、交互呈现和桌面组合，以固定的 gpui-base 与 GPUI 为行为、输入和渲染底座。交付范围覆盖[组件矩阵](../component-coverage.zh.md)的规范和适配项、[设计系统要求](../design-sources.zh.md#material-specification)与[平台质量门槛](../verification.zh.md)。实验项按实际设备和需求评估，兼容项由后续串行阶段处理。

<a id="deliverables"></a>

## 工作单元

| 任务 | 前置 | 改动范围 | 通过证据 |
| --- | --- | --- | --- |
| P0-01 建立文档、许可与阶段入口 | 无 | README、LICENSE、第三方声明、文档索引、阶段规则及状态、根目录忽略规则 | 导航和阶段引用有效，仓库忽略根 `AGENTS.md`，TOML 可解析且阶段状态唯一。 |
| P0-02 核实并锁定设计、源码与依赖 | 无 | `docs/design/`、`docs/architecture/` | 上游发布、tag、包元数据、包摘要、官网快照和算法参考互相对应。 |
| P0-03 核对组件覆盖 | P0-02 | `docs/components/coverage.md` | 官网目录每个组件主题有去向，规划内每个交付有类型、类别、归属、状态、平台和验收方向。 |
| P0-04 定义三平台验收和 P1 探针 | P0-02、P0-03 | `docs/verification.md`、`docs/phases/P01.md` | Windows、macOS、Linux 证据要求明确，探针含依赖、通过条件和阻塞判据。 |

P0 允许上述文档、许可、忽略规则和状态文件。此时依赖组合通过文档契约冻结，P1 在探针中写入精确 Cargo 版本，P2 建立正式 Workspace 与 lockfile。所有组件仍按[阶段归属](../phases.zh.md)进入实现。

<a id="initial-platform-revision"></a>

## 首版平台修订

2026-11-13，项目负责人将首版支持范围定为 Windows 11 x64/MSVC。P1 和后续首版阶段以该平台的完整证据为准。macOS 与 Linux 的探针结果保留供后续支持评估。下表和验收历史记录 P0 初次冻结时的交付。返修见 [#34](https://github.com/wangdiandao/gpui-material/issues/34) 与[当前平台要求](../verification.zh.md)。
