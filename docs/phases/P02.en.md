## Acceptance

[P2 acceptance record](P02-evidence.en.md) covers native execution, build timings, artifacts, and merge checks. [status.toml](../../status.toml) records the acceptance commit and freeze.

- Pin the toolchain, Cargo resolution, and platform dependencies. Check the default packages and Gallery separately. Resolve test features separately from normal builds.
- Open the minimal Gallery window on Windows and confirm visible state, actual scaling, and close behavior. The UI integration test draws the same view and asserts semantics and layout. Verify components and native input in their owning phases.
- Record cold and warm `cargo check`, `cargo build`, and Cargo timelines. Retest with the same machine, features, and target directory policy.
- GitHub Actions covers formatting, linting, tests, documentation, phase paths, dependencies, and the Windows artifact. Link issues in PRs and record verification. Freeze after the `main` merge gate is active.
