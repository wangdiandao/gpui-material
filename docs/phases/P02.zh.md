## 验收

实机、构建计时、托管制品及门禁记录见 [P2 验收记录](P02-evidence.zh.md)。本阶段接受提交与冻结状态见 [status.toml](../../status.toml)。

- 锁定工具链、Cargo 解析和平台依赖。默认包与 Gallery 分开检查，测试 feature 与正常构建分开解析。
- 在 Windows 实机打开最小 Gallery 窗口，核对可见状态、实际缩放和关闭行为。自动化 UI 集成测试绘制同一视图并断言语义及布局。组件和原生输入能力沿所属阶段逐项验收。
- 记录冷/热 `cargo check`、`cargo build` 和 Cargo 时间线。按相同机器、feature 与目标目录策略复测。
- GitHub Actions 覆盖格式、静态检查、测试、文档、阶段路径、依赖与 Windows 制品。PR 关联 Issue 并记录验证，`main` 的门禁生效后执行冻结。
