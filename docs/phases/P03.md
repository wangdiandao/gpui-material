# P3 纯主题

P3 交付可独立构建的 `gpui-material-theme`。主题公开纯值类型，使用离线 Token 数据。P4 在此基础上接入绘制、输入和平台主题。

| 交付 | 前置 | 验收 |
| --- | --- | --- |
| [P3-01 启动](https://github.com/wangdiandao/gpui-material/issues/74) | P2 冻结 | 登记阶段范围和验收条件。 |
| P3-02 主题与生成 | P3-01 | 解析 Reference、System、Component 三层 Token，校验引用与类型，生成 Rust 表和索引。交付色彩、排版、形状、MotionSpec、布局与密度。 |
| P3-03 验收与冻结 | P3-02 | 记录固定来源、官方算法向量、离线再生成、依赖图与 Windows CI 结果，再登记冻结。 |

## 验收条件

- 数据记录固定来源、Material 原名与 Rust 字段。解析器拒绝缺失、循环、非法层级和类型不匹配的引用。CI 对比仓库内生成物。
- 色彩覆盖静态浅深主题、颜色配对、Surface 层级与按源色生成的主题。用固定 MCU 核验源色往返、色板、浅深角色、对比度和固定角色。使用 feature 隔离动态颜色与序列化。
- 对照固定设计来源核验 baseline 与 emphasized 排版、字体回退配置、角形、圆角多边形参数、Standard 和 Expressive 动效，以及可用窗口尺寸、密度、逻辑方向和字体缩放的纯值策略。
- 默认构建和 theme 的普通、开发、构建依赖图均无 GPUI。用纯逻辑测试覆盖边界。记录版本、许可、预期、观察结果和复现命令。
