## Acceptance criteria

- Data records pinned sources, original Material names, and Rust fields. The parser rejects missing, cyclic, illegal-layer, and type-mismatched references. CI compares checked-in generated output.
- Color covers static light and dark themes, color pairing, Surface elevation, and seed-based themes. Use pinned MCU to check seed round trips, palettes, light and dark roles, contrast, and fixed roles. Isolate dynamic color and serialization with features.
- Compare baseline and emphasized typography, font fallback configuration, corners, rounded polygon parameters, Standard and Expressive motion, and pure value policies for available size, density, logical direction, and font scaling against pinned sources.
- Default builds and normal, development, and build dependency graphs for theme exclude GPUI. Use pure logic tests for boundaries. Record versions, licenses, expected and observed results, and reproduction commands.
