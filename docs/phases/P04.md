# P4 Foundation primitives

English | [中文](P04.zh.md)

P4 connects the pure Material theme to GPUI and Base in the `gpui-material-foundation` crate. Gallery exercises each primitive through its public API. Base owns window services, focus, editing, and input state. Foundation owns Material presentation and the adapters verified in P1.

## Acceptance criteria

- Exercise app theme synchronization and local overrides with two windows. Check light and dark surfaces, elevation, scrim, and updates after a theme change.
- Check the pinned rounded polygon topologies, logical corners, shape clipping and hit testing. Verify pointer and keyboard feedback, disabled and cancelled state, reduced motion, continuous retargeting, and that settled animations stop requesting frames.
- Exercise keyboard and semantic activation, roving focus, drag cancellation on Esc and capture loss, overlay dismissal and focus restoration, logical placement, scroll ownership, and slider value labels and actions through the normal Base paths.
- Verify mixed-script text and measurement, font and locale overrides, and applicable native paths on Windows 11 x64. Record reproduction and results in the owning issue or PR. [Platform acceptance](../verification.md)
