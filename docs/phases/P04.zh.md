# P4 基础原语

[English](P04.md) | 中文

P4 在 `gpui-material-foundation` crate 中将纯 Material 主题接入 GPUI 和 Base。Gallery 通过公开 API 验证每项原语。Base 管理窗口服务、焦点、编辑和输入状态。Foundation 管理 Material 呈现和 P1 已验证的适配。

## 验收条件

- 使用两个窗口验证应用主题同步和局部覆盖。检查亮色与暗色表面、高度、遮罩以及切换主题后的更新。
- 检查固定范围内的圆角多边形拓扑、逻辑圆角、形状裁剪和命中测试。验证指针和键盘反馈、禁用和取消状态、减少动效、连续重定向，以及动效停止后不再请求帧。
- 通过 Base 的常规路径验证键盘和语义激活、游走焦点、Esc 和捕获丢失取消拖动、浮层关闭和焦点恢复、逻辑位置、滚动归属，以及滑块值标签和语义操作。
- 在 Windows 11 x64 验证混合文字及测量、字体和区域覆盖以及适用的原生路径。在对应 Issue 或 PR 记录复现步骤和结果。[平台验收](../verification.zh.md)
