# P5 Basic components

English | [中文](P05.zh.md)

P5 adds Material controls and display components on the pinned theme and Foundation. Base owns reusable interaction and retained slider values. Applications own selection and command outcomes. The components crate owns Material presentation. Gallery exercises each family through the public facade.

## Acceptance criteria

- Implement each P5 row in the coverage matrix. Derive visual defaults from the pinned site and Compose sources. Record desktop adaptations in the corresponding PR.
- Exercise the published constructors in Gallery. Verify pointer, keyboard, and semantic activation and cancellation with the actual value owner. Check focus order and independent child actions.
- Check light and dark themes, RTL, mixed-script and long labels, scaled fonts, high DPI, narrow windows, and reduced motion in applicable scenarios. Inspect Windows UI Automation roles, names, values, and relationships, and verify applicable Narrator paths.
- Verify the facade dependency graph and the licensing of distributed assets. Keep default workspace checks available without a GPUI backend. Record commands, environment, and acceptance results in the owning Issue or PR before the freeze.
