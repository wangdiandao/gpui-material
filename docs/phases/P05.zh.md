# P5 基础组件

[English](P05.md) | 中文

P5 在已锁定的主题和 Foundation 上实现 Material 控件及展示组件。Base 负责可复用的交互和滑块保留值，应用负责选中值和命令结果，组件 crate 负责 Material 表现。Gallery 通过公开门面运行各组件族的示例。

<a id="验收条件"></a>

## 验收条件

- 交付覆盖矩阵中的每个 P5 条目。视觉默认值依据已锁定的网站及 Compose 源码，在对应 PR 记录桌面适配。
- 在 Gallery 运行公开构造入口。通过真实的值持有者验证指针、键盘、语义激活和取消，检查焦点顺序及独立子操作。
- 在适用场景检查明暗主题、RTL、混合文字与长标签、字体缩放、高 DPI、窄窗口及减少动效设置。检查 Windows UI Automation 角色、名称、值与关系，并验证适用的讲述人操作。
- 检查门面依赖图和分发资产许可。默认 workspace 检查继续支持无 GPUI 后端的环境。冻结前在所属 Issue 或 PR 记录命令、环境和验收结果。
