# P6 Text fields and overlays

English | [中文](P06.zh.md)

P6 adds Material text fields and overlays to the components crate and exposes them through the facade. Base owns editing, focus scopes, and overlay positioning. Material supplies styling and composition, including the connection between a text field and a dropdown. The application owns commit decisions and commands. Gallery demonstrates the public APIs.

## Acceptance criteria

- Deliver every P6 row in the coverage matrix. Use the pinned design sources and record desktop adaptations in the owning PR.
- Verify real Windows Gallery scenarios with Microsoft Pinyin. Check uncommitted composition, candidate placement, commit, and cancellation in a field, inside a dialog, and in an editable dropdown. Verify secure input and clipboard handling.
- Open and dismiss nested surfaces by keyboard and pointer. Verify modal trapping, Escape order, trigger focus restoration, RTL placement, and independent scrolling. Check applicable light and dark, narrow, high-DPI, long-label, scaled-font, and reduced-motion cases.
- Inspect UI Automation roles, names, descriptions, values, states, and actions. Use Narrator to verify announcements and operability in the native window. Record the environment, steps, and actual outcome in the owning Issue or PR before freezing.
