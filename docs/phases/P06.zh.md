# P6 文本字段与浮层

[English](P06.md) | 中文

P6 在组件 crate 中实现 Material 文本字段及浮层，并通过公开门面提供这些组件。Base 负责编辑、焦点范围与浮层定位。Material 负责视觉表现和组件组合，包括文本字段与下拉菜单的联动。应用负责决定何时提交和执行命令。Gallery 演示公开 API。

<a id="验收条件"></a>

## 验收条件

- 交付覆盖矩阵中的全部 P6 条目。使用已锁定的设计来源，在所属 PR 记录桌面适配。
- 在 Windows 实窗 Gallery 中使用微软拼音，分别在文本字段、对话框内字段和可编辑下拉组件中检查预编辑、候选位置、提交及取消。验证安全输入与剪贴板处理。
- 用键盘和指针打开及关闭嵌套浮层。检查模态焦点限制、Esc 关闭顺序、触发点焦点恢复、RTL 定位和独立滚动。在适用场景验证明暗主题、窄窗口、高 DPI、长标签、字体缩放与减少动效设置。
- 用 UI Automation 检查角色、名称、说明、值、状态与动作。使用讲述人验证原生窗口中的播报与操作。冻结前在所属 Issue 或 PR 记录环境、步骤与实测结果。
