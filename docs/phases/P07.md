# P7 Navigation and adaptive layout

English | [中文](P07.zh.md)

P7 adds navigation components and adaptive layout patterns to the Material facade. Callers own destination, pane, and content state. Material arranges the slots and applies interaction, appearance, and focus behavior. Gallery exercises the public APIs in a Windows window.

## Acceptance criteria

- Deliver every P7 row in the coverage matrix against the pinned Material 3 and Compose Adaptive sources. Record desktop adaptations in the owning PR.
- Resize through compact, medium, and expanded widths in both directions. Verify selected destination, pane content, focus, independent scroll positions, and the single-pane back path.
- Verify keyboard activation and directional movement, selection and focus visibility, disabled items, modal rail dismissal and focus restoration, and visible selection in overflowing tabs and rails.
- Verify LTR and RTL, light and dark, display and font scaling, long labels, and native Windows UI Automation roles, labels, states, and actions. Record the environment and results in the owning Issue or PR.
