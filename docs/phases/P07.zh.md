# P7 导航与自适应布局

[English](P07.md) | 中文

P7 将导航组件和自适应布局模式加入 Material 门面。调用方持有目的地、窗格和内容状态。Material 排列插槽并提供交互、外观和焦点行为。Gallery 在 Windows 窗口中使用公开 API。

| [P7-04 Windows 验收与预览](https://github.com/wangdiandao/gpui-material/issues/179) | P7-02 和 P7-03 | 记录 Windows 和 CI 结果，冻结 P7，交付 0.0.2 Gallery 预览。 |

## 验收条件

- 按固定版本的 Material 3 和 Compose Adaptive 源码交付覆盖矩阵中的全部 P7 项目。桌面适配记录在相应 PR。
- 双向调整窗口尺寸，经过紧凑、中等和展开宽度。验证目的地选择、窗格内容、焦点和独立滚动位置的延续，以及单窗格返回路径。
- 验证键盘激活和方向键移动、激活项和焦点的可见性、禁用项、模态导航栏关闭后的焦点恢复，以及溢出标签页和导航栏中的选中项可见性。
- 验证 LTR 和 RTL、明暗主题、显示和字体缩放、长标签，以及 Windows 原生 UI Automation 的角色、名称、状态和操作。在相应 Issue 或 PR 中记录环境与结果。
