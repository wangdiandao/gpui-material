# P8 Composite and extended components

English | [中文](P08.zh.md)

P8 adds optional component families to the Material facade. The implementation builds on the frozen controls, input, overlay, and navigation contracts. Gallery exercises each family through the public facade. Applications enable only the families they use.

## Acceptance criteria

- Deliver all required P8 rows against the pinned Material 3 sources. Record desktop adaptations and experimental decisions in their owning issues or PRs.
- Verify that each facade feature builds independently and that optional date dependencies stay out of builds which omit the date-time family.
- Exercise pointer, keyboard and semantic activation, disabled states, stable selection, overlay focus and dismissal, RTL, narrow widths, and themes including reduced motion where applicable.
- Verify real-window Windows 11 x64/MSVC behavior, including UI Automation, Narrator, Chinese Pinyin IME, and native scroll and focus paths. Record the environments, commands, and results in the corresponding issues or PRs.
- Publish the candidate as 0.0.4. The published [0.0.3 preview](https://github.com/wangdiandao/gpui-material/releases/tag/v0.0.3) contains an outlined-text-field repair.
