# P8 复合与扩展组件

[English](P08.md) | 中文

## 验收标准

- 按固定版本的 Material 3 来源交付 P8 的全部必需项。各桌面适配和实验结论记入对应 Issue 或 PR。
- 验证每个门面特性能独立构建。日期时间族可选地直接依赖 Base 和 GPUI 已使用的 chrono 版本。
- 验证指针、键盘和语义激活、禁用状态、稳定选择、浮层焦点与关闭、RTL、窄窗口和主题，并在适用时验证减少动效。
- 在 Windows 11 x64/MSVC 真实窗口验证 UI Automation、讲述人、中文拼音 IME 及原生滚动和焦点路径。将环境、命令和结果记入对应 Issue 或 PR。
- 候选版使用 0.0.4。已发布的 [0.0.3 预览版](https://github.com/wangdiandao/gpui-material/releases/tag/v0.0.3)包含描边文本字段修复。

## 实验结论

| 模式 | P8 决定 | 重新评估所需验证 |
| --- | --- | --- |
| PullToRefresh | 暂缓。候选版没有以触摸为主的刷新场景。 | 在支持的输入硬件上验证滚动边界取消、只刷新一次，以及等效键盘动作。 |
| SwipeToDismiss | 暂缓。候选版没有以触摸为主且支持撤销的关闭场景。 | 验证阈值、取消、RTL、撤销，以及等效键盘和语义动作。 |
| TimeScroll | 暂缓。表盘和输入覆盖已支持的时间选择任务。 | 验证滚动变体的滚轮和键盘导航、边界以及原生播报。 |
