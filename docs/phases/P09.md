## Acceptance criteria

- Verify the public facade from a downstream crate on Rust 1.99.1. Compare the 0.0.4 and P9 public surfaces, documenting any required changes and the support policy for optional features and upstream types.
- Apply the [platform acceptance criteria](../verification.md) to the initial Windows 11 x64/MSVC scope. Exercise representative integrated paths in a real window and record the input, scaling, assistive technology and environments exercised. Use the P0–P8 results for the owning components and identify hardware or environments that still lack coverage.
- Check normal and test dependency graphs and run required CI on Windows, macOS, and Linux. Use equivalent Windows environments and Cargo settings to compare cold and warm checks and builds with the 0.0.4 candidate.
- From the locked Windows build, assemble a standalone ZIP with the executable, license material, and a SHA-256 checksum. Verify the checksum, extract the package to a clean directory, and launch and exercise the executable there.
