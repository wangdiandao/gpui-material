## 验收标准

- 在 Rust 1.99.1 下用下游 crate 验证公开门面。对比 0.0.4 和 P9 的公开 API，记录必要的迁移改动以及可选特性和上游类型的支持策略。
- 对首发 Windows 11 x64/MSVC 范围采用[平台验收标准](../verification.zh.md)。在真实窗口复测代表性集成路径，记录已检查的输入、缩放、辅助技术和环境。引用 P0–P8 各组件的验收结果，并注明尚缺覆盖的硬件或环境。
- 校验常规和测试依赖图，并在 Windows、macOS、Linux 运行必需 CI。在等效的 Windows 环境和 Cargo 设置下与 0.0.4 候选版本对比冷、热检查和构建。
- 从锁定的 Windows 构建生成独立 ZIP，包含可执行文件、许可材料和 SHA-256 校验值。核对校验值，在干净目录解压并启动、操作可执行文件。
